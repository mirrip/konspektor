# Конспектор

Android-приложение для себя: записывает урок с микрофона, режет на части по 5 минут
(с перекрытием 3 секунды), отправляет каждую часть в Groq Whisper и складывает
текст в приватный репозиторий GitHub. Оттуда его забирает Codex на компьютере, чтобы
разложить по предметам, сделать конспект и найти домашку. Результат возвращается на телефон.

## Как это работает

1. Нажимаешь большую кнопку **«Включить»**. Запускается фоновая служба, поэтому
   запись продолжается при выключенном экране. Разрешение на уведомления не нужно.
   Предмет по умолчанию «Общий»: потом урок разберёт Codex. Выбрать предмет вручную
   можно кнопкой слева сверху.
2. Каждые 5 минут готовая часть (`.m4a`, около 1,2 МБ) уходит в Groq. Перед тем как
   текст попадёт в урок, фильтр вырезает фразы, которые Whisper выдумывает в тишине.
3. Если связи нет, части ждут в очереди и отправляются позже. Аудио всегда остаётся
   на телефоне.
4. Нажимаешь **«Выключить»**. Приложение дорасшифровывает остаток, пишет `done.txt`,
   и текст урока уходит в репозиторий.
5. Когда Codex разберёт урок, при следующей синхронизации (открытие приложения или
   кнопка в настройках) приходят предмет, тема, конспект и домашка.

## Расшифровка

Groq, модель `whisper-large-v3-turbo`, язык `ru`, температура 0, ответ `verbose_json`
(текст и отрезки с временем).

**Подсказка для Whisper** (Настройки → Расшифровка). Whisper не выполняет команды:
подсказку он читает как текст, сказанный перед записью, и подстраивает под неё стиль,
пунктуацию и написание слов. Поэтому туда стоит писать термины, имена и фамилии с уроков,
а не «ничего не додумывай». Проверено 16.11.2026 на тишине:
- без подсказки Whisper выдумал «Продолжение следует…»;
- с подсказкой «Ничего не додумывай. Пиши дословно» — «Субтитры создавал DimaTorzok».

К каждой части уходит: подсказка + «Предмет: …» (если выбран) + конец предыдущей части.
Groq принимает не больше 896 байт (около 450 русских букв), приложение укладывается в
880. Если Groq всё же отклонит подсказку, часть отправляется ещё раз без неё.

**Фильтр выдуманных фраз** (включён по умолчанию). У `whisper-large-v3-turbo` на Groq
вероятность тишины (`no_speech_prob`) всегда 0, поэтому выдумки ищутся по виду
(`WhisperFilter.kt`):
- пара слов, растянутых на 6+ секунд (меньше 0,4 слова в секунду);
- известные титры YouTube: «Продолжение следует», «Субтитры сделал/создавал…»,
  «Спасибо за просмотр»;
- отрезки без речи (`[МУЗЫКА]`, ♪);
- одна и та же фраза подряд, повтор текста подсказки;
- петли «Я не знаю. Я не знаю. Я не знаю.» (больше двух одинаковых предложений подряд).

Всё вырезанное с временем и причиной лежит в `parts/chunk_NNN.removed.txt`, число видно в уроке.

## Синхронизация с GitHub

Настройки → «Синхронизация с GitHub»: fine-grained токен только к одному приватному
репозиторию (Contents: read and write) и его имя, по умолчанию `mirrip/konspektor-data`.
Синхронизация запускается при открытии приложения и после каждой записи.

| Где в репозитории | Кто пишет | Что это |
|---|---|---|
| `inbox/<lessonId>/transcript.txt`, `meta.json` | телефон | готовый урок; в `meta.json`: `complete`, `started`, `started_ms`, `duration_sec`, `chunks`, `failed_chunks`, `device`, `subject_hint` (если выбран), `resent: true` (если урок уже был разобран, а потом дорасшифрован) |
| `index.json` → `lessons[lessonId] = {subject, topic, number, path}` | Codex | где лежит разобранный урок |
| `<path>/konspekt.md` | Codex | конспект |
| `homework/<id>.json` | Codex и телефон | одно задание: `id, subject, text, due, lesson, source, done, created` |

`lessonId` = имя папки урока на телефоне + 4 символа телефона, поэтому уроки с двух
телефонов не путаются.

Сколько стоит одна синхронизация, не зависит от размера репозитория: запрос «на каком
коммите ветка» (40 байт), если что-то изменилось — один `compare` с прошлого раза, потом
только изменившиеся файлы. Полный проход (первый раз или 300+ изменённых файлов) читает
список двух папок: корня и `homework/`. Весь репозиторий целиком телефон не перечисляет.

## Где лежат файлы на телефоне

`Документы/Konspektor/<дата_предмет>/`:

| Файл | Что это |
|---|---|
| `meta.txt` | предмет, время начала, `id` урока |
| `audio/chunk_001.m4a` | части записи |
| `parts/chunk_001.txt` | расшифровка части (`.failed` — не удалось, `.removed.txt` — что вырезал фильтр) |
| `transcript.txt` | весь текст урока с отметками времени `[мм:сс]` |
| `done.txt` | урок полностью расшифрован |
| `synced.txt` | какой текст уже отправлен в репозиторий |
| `info.json` | предмет, тема и номер из `index.json` (после разбора Codex) |
| `konspekt.md` | конспект из репозитория, приложение показывает его на вкладке «Конспект» |

В корне `Konspektor/`: `homework.json` (домашка на телефоне, синхронизируется с
`homework/` в репозитории) и `.index.json` (копия `index.json`).

Номера уроков приложение считает само: по порядку дат внутри предмета.

Если общая папка «Документы» недоступна, приложение пишет в свою папку.
Путь показан в настройках.

## Установка на телефон

**Проще всего:** открыть на телефоне ссылку
https://github.com/mirrip/konspektor/releases/latest/download/Konspektor.apk
и установить скачанный файл (разрешить установку из браузера). Новая версия ставится
поверх старой, записи и ключи сохраняются.

### Через кабель

1. На телефоне: **Настройки → О телефоне → 7 раз нажать «Номер сборки»**, затем
   **Для разработчиков → Отладка по USB**: включить.
2. Подключить телефон кабелем и разрешить отладку на телефоне.
3. На компьютере:

```bash
"%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe" install -r Konspektor.apk
```

### Ключ Groq

Ключ в коде не хранится. Его вставляют в настройках приложения или передают с
компьютера по кабелю:

```bash
adb shell am start -n app.konspektor/.MainActivity --es groq_key gsk_ВАШ_КЛЮЧ
```

### Чтобы запись не убивалась в фоне

В приложении: **Настройки → «Разрешить работу в фоне»**. На Xiaomi, Huawei и
Samsung ещё стоит включить для приложения «Автозапуск» и снять ограничения батареи
в настройках приложения.

## Сборка

```bash
gradlew.bat assembleRelease
```

Нужен JDK 17+ (подходит встроенный в Android Studio: `C:\Program Files\Android\Android Studio\jbr`).
APK: `app/build/outputs/apk/release/app-release.apk` (сжат R8, подписан тем же ключом,
что и прошлые версии).

Версии: Gradle 9.6.0, Android Gradle Plugin 9.5.1 (встроенный Kotlin 2.4.20),
compileSdk 37, targetSdk 36, minSdk 26 (Android 8+).

### Тесты

`WhisperFilterTest` проверяет фильтр на настоящих ответах Groq. `GitHubApiTest` проверяет
запросы синхронизации к настоящему репозиторию, только чтение. `TranscriberLiveTest`
отправляет настоящий запрос в Groq. Последние два пропускаются без файлов с ключами:
`-Dkonspektor.tokenFile=…`, `-Dkonspektor.groqKeyFile=…`, `-Dkonspektor.audio=…`.

Если в пути к проекту есть кириллица, запускать через `JUnitCore`: тестовый раннер
Gradle на таком пути не находит классы.
