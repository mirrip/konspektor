# Конспектор

Android-приложение для себя: записывает урок с микрофона, режет на части по 5 минут
(с перекрытием 3 секунды), отправляет каждую часть в Groq Whisper и складывает
текст в папку, откуда его забирает Codex на компьютере, чтобы сделать конспект.

## Как это работает

1. Нажимаешь большую кнопку **«Начать запись»**. Запускается фоновая служба, поэтому
   запись продолжается при выключенном экране. Разрешение на уведомления не нужно.
   Предмет по умолчанию «Общий»: потом урок разберёт Codex. Выбрать предмет вручную
   можно маленькой кнопкой справа.
2. Каждые 5 минут готовая часть (`.m4a`, около 1,2 МБ) уходит в Groq. Текст появляется
   в приложении.
3. Если связи нет, части ждут в очереди и отправляются позже. Аудио всегда остаётся
   на телефоне.
4. Нажимаешь **«Остановить»**. Приложение дорасшифровывает остаток и пишет `done.txt`.

## Где лежат файлы

`Документы/Konspektor/<дата_предмет>/` на телефоне:

| Файл | Что это |
|---|---|
| `meta.txt` | предмет и время начала |
| `audio/chunk_001.m4a` | части записи |
| `parts/chunk_001.txt` | расшифровка каждой части (`.failed` — если не удалось) |
| `transcript.txt` | весь текст урока с отметками времени `[мм:сс]` |
| `done.txt` | урок полностью расшифрован, можно делать конспект |
| `info.json` | **пишет Codex**: `{"subject": "Физика", "topic": "Законы Ньютона"}` |
| `konspekt.md` | **пишет Codex**: конспект урока, приложение показывает его на вкладке «Конспект» |

В корне папки `Konspektor/` лежит `homework.json` — домашка. Её находит **Codex** в тексте
урока (учитель произносит задание вслух) и дописывает в массив:

```json
{"id": 1731770000000, "subject": "Физика", "text": "№12 и 15", "due": "к пятнице",
 "lesson": "2026-11-16_14-00_Общий", "source": "codex", "done": false, "created": 1731770000000}
```

`done` меняет приложение, когда задание отмечено выполненным. `id` должен быть уникальным.

Номера уроков приложение считает само: по порядку дат внутри предмета, после того как
Codex указал предмет в `info.json`.

Если общая папка «Документы» недоступна, приложение пишет в свою папку.
Путь показан внизу экрана.

## Установка на телефон

**Проще всего:** открыть на телефоне ссылку
https://github.com/mirrip/konspektor/releases/latest/download/Konspektor.apk
и установить скачанный файл (разрешить установку из браузера).

### Через кабель

1. На телефоне: **Настройки → О телефоне → 7 раз нажать «Номер сборки»**, затем
   **Для разработчиков → Отладка по USB**: включить.
2. Подключить телефон кабелем и разрешить отладку на телефоне.
3. На компьютере:

```bash
"%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe" install -r Konspektor.apk
```

Можно и без кабеля: перекинуть `Konspektor.apk` на телефон (например, через Telegram)
и открыть его, разрешив установку из этого источника.

### Ключ Groq

Ключ в коде не хранится. Его можно вставить в поле внизу экрана приложения или
передать с компьютера по кабелю:

```bash
adb shell am start -n app.konspektor/.MainActivity --es groq_key gsk_ВАШ_КЛЮЧ
```

### Чтобы запись не убивалась в фоне

В приложении: **Настройки → «Разрешить работу в фоне»**. На Xiaomi, Huawei и
Samsung ещё стоит включить для приложения «Автозапуск» и снять ограничения батареи
в настройках приложения.

## Сборка

```bash
gradlew.bat assembleDebug
```

Нужен JDK 17+ (подходит встроенный в Android Studio: `C:\Program Files\Android\Android Studio\jbr`).
Готовый APK для телефона: `gradlew.bat assembleRelease` → `app/build/outputs/apk/release/app-release.apk` (сжат R8, подписан тем же ключом).

Версии: Gradle 9.6.0, Android Gradle Plugin 9.5.1 (встроенный Kotlin), compileSdk 37,
targetSdk 36, minSdk 26 (Android 8+). Сторонних библиотек нет.
